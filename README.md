# Rohan Kumar — Developer Portfolio

Frontend & Full-Stack Developer portfolio built with **React 19**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.

## Features

- **Interactive UI Craft Lab**: Live Bézier motion scrubber (extracted from Ultimate Frisbee Strategy Platform) and live Glassmorphism Surface Token Studio.
- **Filterable Project Showcase + Case Study Modal**: Inspect architecture decisions, frontend craft highlights, live Vercel deployments, and public GitHub repos.
- **Self-Hosted Public Resume**: Accessible directly at `/Rohan_Kumar_Resume.pdf` (no external Drive permission walls).
- **Instant Dark / Light Mode** with persistent theme preference and responsive layout.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

Deploy the `dist/` folder directly to **Netlify Drop**, **Vercel**, or **GitHub Pages**.
